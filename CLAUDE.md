# rewear

Community marketplace for second-hand clothes (small business, one admin).

- Read `docs/ARCHITECTURE.md` before making or proposing any architectural or
  technology decision. Changes must conform to its decision records; to
  contradict one, explicitly revisit the relevant ADR.
- `docs/ROADMAP.md` lists anticipated changes and deferred features — check it
  before proposing new work, and keep it updated when plans change.
- Product changes go through the OpenSpec workflow (`openspec/`), one
  incremental change at a time.
